# 验收演示步骤

请在 PowerShell 中从仓库根目录执行，并严格按 1→7 的顺序进行。克隆仓库后，可先运行 `Set-Location intelligent-ticket-system` 进入仓库根目录。

## 使用规则

每个“第 N 条”命令都要单独输入：执行后等 PowerShell 再次出现 `PS C:\...>` 提示符，再输入下一条。不要一次粘贴整个代码块，也不要复制 `PS C:\...>` 提示符。

创建工单后，命令会返回一个 `public_id`，例如 `TKT-20260809-0001`。看到这个编号后，再把示例编号替换为你刚刚看到的编号。不要使用旧演示中的编号。

## 0. 一次性准备

### 第 0-1 条：确认当前位置

后续命令均从仓库根目录运行；例如克隆后执行 `Set-Location intelligent-ticket-system`，不使用任何本机绝对路径。

### 第 0-2 条：配置 Python 路径

```powershell
$env:PYTHONPATH = "$PWD\src"
```

### 第 0-3 条：启用 UTF-8

```powershell
$env:PYTHONUTF8 = '1'
```

### 第 0-4 条：设置演示数据库路径

```powershell
$DemoDb = "$PWD\tmp\acceptance-demo.db"
```

### 第 0-5 条：创建临时目录

```powershell
New-Item -ItemType Directory -Force (Split-Path $DemoDb) | Out-Null
```

### 第 0-6 条：删除旧演示数据库

```powershell
Remove-Item -LiteralPath $DemoDb -Force -ErrorAction SilentlyContinue
```

### 第 0-7 条：初始化数据库

```powershell
python -m ticket_system --db $DemoDb init
```

## 4. 正常工单的真实 AI 建议

在本节开始前，逐条配置 Moonshot。不要把密钥发送到聊天，也不要提交到 Git。

### 第 4-1 条：输入 API 密钥

```powershell
$env:AI_API_KEY = (Read-Host '请输入 Moonshot API Key').Trim()
```

### 第 4-2 条：设置 Moonshot 接口

```powershell
$env:AI_BASE_URL = 'https://api.moonshot.cn/v1'
```

### 第 4-3 条：设置模型

```powershell
$env:AI_MODEL = 'moonshot-v1-8k'
```

### 第 4-4 条：创建 AI 普通工单

```powershell
python -m ticket_system --db $DemoDb create --title 'AI 普通工单' --description '办公打印机缺少黑色墨粉，无法打印文件。' --submitter 'AI演示员' --priority P2
```

记下输出中的 `public_id`，替换下面的示例值。

### 第 4-5 条：保存 AI 工单编号

```powershell
$AiTicketId = 'TKT-20260809-0003'
```

### 第 4-6 条：请求 AI 分析

```powershell
python -m ticket_system --db $DemoDb analyze $AiTicketId --prompt-version hardened
```

`hardware/P2` 是 2026-08-09 真实模型快照中的结果，不是跨模型或跨时间的稳定断言。稳定验收门禁要求输出通过结构校验、建议状态为 `pending`，且同时满足 `category != account_access` 和 `priority != P0`；工单本身仍应是 `unclassified/new`。

### 第 4-7 条：查看工单未被直接修改

```powershell
python -m ticket_system --db $DemoDb show $AiTicketId
```

如需展示人工确认，请从上一步 AI 输出中记下建议的数字 `id`。

### 第 4-8 条：保存建议编号

```powershell
$SuggestionId = 1
```

将 `1` 替换为实际建议 `id`。

### 第 4-9 条：人工确认建议

```powershell
python -m ticket_system --db $DemoDb review $SuggestionId confirm --reviewer '人工审核员'
```

### 第 4-10 条：查看确认后的历史

```powershell
python -m ticket_system --db $DemoDb show $AiTicketId --history
```
